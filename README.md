# 📰 News Sentiment Tracker

Мини-сервис на **FastAPI**, который парсит новости из RSS-лент, определяет их тональность (позитив / негатив / нейтрально), сохраняет в базу и отдаёт через REST API. Плюс простая аналитика — топ самых негативных новостей.

Учебный проект для практики: **парсинг → БД → ML-подход к анализу текста → API → аналитика данных**.

---

## 🚀 Возможности

- 📥 Парсинг новостей из публичных RSS-лент (`feedparser`)
- 🧠 Определение тональности заголовка (словарный метод, легко заменить на ML-модель)
- 🗄️ Хранение новостей в SQLite через **SQLAlchemy 2.0**
- 🌐 REST API на **FastAPI** с автодокументацией (Swagger UI)
- 📊 Аналитика через **pandas**: топ самых негативных новостей
- 🛡️ Защита от дублей (уникальный `link`)

---

| Слой | Технология |
